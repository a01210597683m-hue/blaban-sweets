# Blaban Sweets — متجر حلو بلبن الإلكتروني

واجهة أولية عربية باتجاه RTL ومتجاوبة مع الموبايل والكمبيوتر.

## الحالة الحالية
- صفحة رئيسية ومنيو فارغ متعمّد إلى أن تُضاف المنتجات والأسعار المعتمدة.
- أقسام تعريفية للفروع والتوصيل والتواصل، بدون اختلاق بيانات.
- هذه الواجهة **ليست بعد متجرًا متكاملًا**: لا توجد قاعدة بيانات أو تسجيل دخول أو لوحة إدارة فعلية أو سلة/طلبات محفوظة أو دفع إلكتروني في هذه المرحلة.

## تشغيل محلي
افتح ملف `index.html` في المتصفح.

## الخطوات التالية
1. اعتماد الهوية البصرية والشعار والصور الرسمية.
2. إضافة تطبيق خلفي وقاعدة بيانات وصلاحيات إدارة آمنة.
3. تنفيذ المنتجات والسلة والطلبات ومناطق التوصيل.
4. إعداد بوابة دفع بعد اختيار مزوّد مناسب وتفعيلها باختبارات.
5. الاختبار والنشر على استضافة مناسبة.

لا تُدخل مفاتيح سرية أو بيانات دفع في ملفات الواجهة الأمامية.
