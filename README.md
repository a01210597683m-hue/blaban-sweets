# حلو بلبن — متجر إلكتروني

موقع عربي باتجاه RTL ومتجاوب مع الموبايل والكمبيوتر.

## الملفات
- `index.html`: واجهة المتجر.
- `admin.html`: واجهة لوحة الإدارة المتجاوبة.
- `supabase-schema.sql`: مخطط بداية لقاعدة البيانات.

## الحالة الحالية
واجهة المتجر وتصميم لوحة الإدارة موجودان. **لوحة الإدارة ليست مفعّلة بالكامل بعد**؛ يلزم إعداد مشروع Supabase، وتكوين تسجيل الدخول، وإضافة سياسات صلاحيات إدارية آمنة قبل أن تتمكن الإدارة من حفظ المنتجات والاطلاع على الطلبات عبر الأجهزة. لا توجد بعد سلة وطلب متكاملان أو دفع إلكتروني.

## إعداد قاعدة البيانات
1. أنشئي مشروعًا في Supabase.
2. راجعي ملف `supabase-schema.sql` وشغّليه من SQL Editor. هذا المخطط بداية فقط وليس إعدادًا إنتاجيًا كاملًا.
3. قبل تمكين لوحة الإدارة، أضيفي جدولًا موثوقًا لصلاحيات المديرين وسياسات RLS تمنح الكتابة للمسؤولين فقط. لا تنشئي سياسات عامة تسمح بقراءة الطلبات أو تعديلها.
4. انسخي عنوان المشروع والمفتاح العام (anon/publishable) إلى الثابتين `SUPABASE_URL` و`SUPABASE_ANON_KEY` داخل `admin.html` بعد إكمال سياسات الأمان. لا تضعي أبدًا مفتاح `service_role` في المتصفح أو المستودع.
5. أنشئي حساب المدير من لوحة Supabase Auth، واختبري أن الحساب غير المصرح له لا يستطيع إضافة/تعديل المنتجات أو قراءة بيانات الطلبات.

## مهم قبل الإطلاق
- لا تحفظي بيانات حساسة أو مفاتيح سرية في ملفات الواجهة الأمامية.
- نظام الطلبات يجب أن يتحقق خادميًا من أسعار المنتجات والإجمالي والتوفر؛ لا يثق في السعر القادم من المتصفح.
- الدفع الإلكتروني والتوصيل يحتاجان إعدادًا منفصلًا واختبارات قبل استقبال طلبات حقيقية.
